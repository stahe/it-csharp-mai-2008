## Panoramica del linguaggio e della piattaforma .NET

C# è un linguaggio rilasciato ufficialmente nel febbraio 2002, insieme alla piattaforma .NET 1.0 di Microsoft, alla quale è intrinsecamente legato. C# richiede questo ambiente di runtime per funzionare, il quale fornisce un insieme molto esteso di classi.

A prima vista, la piattaforma .NET è un ambiente di runtime simile a una macchina virtuale Java, con alcune differenze degne di nota:

**Multipiattaforma**: mentre Java è stato eseguito su vari sistemi operativi sin dal suo inizio, .NET era inizialmente limitato a Windows. Tuttavia, il progetto **[Mono](http://www.mono-project.com)** ora consente di utilizzare .NET su sistemi come Unix e Linux.


**Multilingue**: la piattaforma .NET consente l'esecuzione di programmi scritti in linguaggi diversi, a condizione che il loro compilatore produca codice IL (Intermediate Language). Tutte le classi .NET sono disponibili per questi linguaggi, il che tende a sfumare le differenze tra loro; la scelta di un linguaggio .NET diventa quindi una questione di preferenza piuttosto che di prestazioni.





## Evoluzione del linguaggio

Nel 2002 (C# 1.0), il linguaggio era molto simile a Java, rendendo più facile il passaggio da un ambiente all'altro. Da allora, le caratteristiche specifiche di ciascun linguaggio sono diventate più distinte.

Con l'arrivo di C# 3.0 e del framework .NET 3.5, sono emerse numerose nuove funzionalità, la più significativa delle quali è probabilmente **LINQ** (Language INtegrated Query). LINQ consente di interrogare array, elenchi, database o file XML in modo uniforme (simile a SQL).
